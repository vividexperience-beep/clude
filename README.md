# 忘れ物チェック

現場の作業ごとに、当日持っていく材料・道具・機械のチェックリストを作れるオフライン対応アプリです。

## 特徴

- 作業(現場)ごとにテンプレートを作成し、チェックリストとして使い回せます
- 管更生工事の作業別サンプルテンプレート付き(調査・前処理・製管、ウエイト・注入・仕上げ・製管、注入)
- 通常画面では持ち物を追加してチェックするだけのシンプルな操作。誤って項目を消してしまうことがありません
- 削除・名前の変更・チェック状態のリセットは「編集」ボタンから入る専用モードでのみ可能。複数選択してまとめて削除、1件選択で名前を変更できます
- データはブラウザ内(localStorage)に保存され、外部通信なしで動作。オフラインでも利用できます
- ホーム画面に追加すればアプリのように起動できます(PWA)

## 使い方

`index.html` を開くだけで動作します。ローカルで確認する場合は、リポジトリのディレクトリで簡易サーバーを立てて開いてください。

```
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/index.html` を開きます。

そのままファイルとして `index.html` を直接ブラウザで開いても、チェックリストの作成・編集・保存は問題なく動作します(サービスワーカーによるホーム画面追加/オフラインキャッシュは、`http://` または `https://` 経由で開いた場合のみ有効です)。
