# 楽曲構成と作詞の資料

作成: 2026-09-21

**作った理由**: `songs/`で構成が似通う件を何度も指摘されたため調査した。

**⚠️ 2026-09-21訂正: 当初ここに「原因は語彙の不足。セクション名が実質7種類しかない」と
書いたが、数え直したら誤りだった。** 実測すると**構造ラベルは31種類、ファイルは28**あり、
**うち24種類は「1曲でだけ」使われている。** 在庫はあって、**上位7つに偏っていた**だけ。

なお**J-POPの用語体系(Cメロ/大サビ/落ちサビ)と形式名(AABA等)を一度も使っていない**のは事実。

## 1. そもそも体系が2つある

> 欧米のポピュラー音楽が「**Verse・Chorus**」というシンプルな往復を基本とするのに対し、
> 日本のJ-POPは「**Aメロ・Bメロ・サビ**」という**3段階**の展開を好む傾向がある
> ([JBG音楽院](https://jbg-ongakuin.com/staff-blog/20260302/))

**こちらは欧米式(2段階)の語彙だけで、日本語の曲を書いていた。**
`Pre-Chorus`を足して3段階にしてはいたが、**J-POP側の用語で考えたことが一度も無い。**

## 2. J-POP側の部品で、うちに無かったもの

| 用語 | 定義 | うちの扱い |
|---|---|---|
| **Cメロ** | **2番のサビ以降に出る新しいセクション**。大サビ前の展開部 | 全部`Bridge`で処理していた |
| **Dメロ** | さらに別のセクション。**テンポやキーごと変える**ことで意外性を出す | 存在すら使っていない |
| **大サビ** | **最後のサビの前に来る、サビとは異なる独自のメロディ** ([ボイカル](https://guitar-concierge.jp/voice/music-term/oosabi/)) | **`Final Chorus`を大サビのつもりで使っていたが定義が違う**(あちらは「最後のサビ」) |
| **落ちサビ** | **ラスサビ直前に音を減らし、ボーカルだけを立たせる**。アニソン・アイドル・バラードの「泣かせどころ」 | 0件 |

**⚠️ 定義は人によって揺れる**という記述もある([東京indie](https://tokyo-indie-band.com/2022/08/music-sabi.html))ので、
大サビ/落ちサビの語は**人と話す時は定義を確認してから使う**。

### ★J-POPヒット曲の最頻出「勝ちパターン」

> **Cメロ(盛り上げる) → 落ちサビ(静かになる) → ラストサビ(半音上げ+全楽器爆発)**
> ([EverPlay](https://everplay.jp/column/27411) / [作曲＆DTM講座](https://akutsuki-music.com/arrangement10/))

**うちは`songs/21-furuki-meiyaku.md`で半音上げだけやったが、
Cメロも落ちサビも一度も入れていない。** 3点セットのうち1点しか使っていなかった。

## 3. 形式そのもの(うちが一度も使っていない4つ)

出典: [Song structure (Wikipedia)](https://en.wikipedia.org/wiki/Song_structure) /
[Open Music Theory](https://viva.pressbooks.pub/openmusictheory/chapter/aaba-and-strophic-form/) /
[Orphiq](https://orphiq.com/resources/song-structure-guide)

| 形式 | 中身 | 使いどころ |
|---|---|---|
| **Strophic(有節形式・AAA)** | **全部の詩節を同じメロディで歌う。サビが無い。** ブルース、初期ヒップホップ、初期ロック | 物語を淡々と積む曲。**サビという「山」を作らない選択** |
| **AABA(32小節形式)** | **A A B A。** Aが3回、Bが1回だけ対比として入る。**独立したサビが無い** | Aがフックを兼ねる。**Bは1回しか来ないので、そこに全部賭けられる** |
| **Through-composed(通作形式)** | **何一つ繰り返さない。** 各セクションに新しい音楽 | 物語が一方向に進み、戻らない曲 |
| **Verse-Refrain** | **各Verseの最後に短いリフレイン行を置く。独立したサビセクションは無い** | フックは欲しいがサビの塊は要らない時 |

**AABAは「A A B A」なのでAが同じ**だが、
> 最初のAは次のAへ戻る形で終わり、2番目のAはBへ繋がる形で終わる

つまり**同じAでも終わり方だけ変える**。これは
CLAUDE.mdの「サビ再登場時はフック以外を書き換える」と**同じ発想の、もっと古い形**。

## 4. 作詞側で採れる手順

出典: [ライブUtaTen](https://utaten.com/live/lyrics-tips/) /
[マサツム](https://note.com/masatsumu/n/n302a501cf3ae) /
[エンタメクロス](https://www.ticket.co.jp/entx/music/lyric_writing_tips/)

- **単語リスト法**: テーマを一言で書き、**関連する単語を20個ほど箇条書き**にしてから書き始める。
  **最も強いフレーズをサビに置き**、Verseは「説明ではなく**状況**」を書く。
- **音数を先に全部取る**: 音源を聴きながら**AメロからサビまでのMora数を全部数えて紙の左端にメモ**する。
  **全体が見えてからストーリーを展開する**。
  → こちらは毎回「書いてから数える」順でやっていた。**逆にすると構成から発想できる。**
- **説明しすぎない**: 分かりやすすぎる言葉・説明過多は
  **リスナーが感情移入するきっかけを奪う**。
- **サビにタイトルを意識した語を置く**と曲全体に統一感が出る。

### 視点と時制

出典: [Past Orange](https://past-orange.com/po_sp/?p=1406) /
[小説の書き方講座](https://kakuyomu.jp/works/1177354054882619171/episodes/1177354054882619271)

- **一人称・二人称の選び方が、立場や年齢そのものを決定する**(僕/私/俺/あたし)。
- **時制が変わると視点がぶれる。** 現在形＝その人物の視点を借りた描写、
  過去形＝第三者の視点からの描写に寄る。
- **現在形と過去形を混在させるのは高度な技法**として挙げられている。
  → **うちは全曲ほぼ現在形で通している。時制の切り替えを構成に使ったことが無い。**

## ⚠️ Sunoでの実装上の注意(ここは別問題)

**上記はすべて「曲の設計」の話であって、「Sunoのブラケットに何と書くか」ではない。**

- **日本語のセクション名(`[Aメロ]` `[大サビ]` `[落ちサビ]`)は、
  うちでもSuno公式でも実績ゼロ。** 使うなら未検証と断った上で確認を取ること。
- **落ちサビをSunoでどう書くかは未検証。**
  ただし`songs/24-ten-no-ginshi.md`の`Instruments Cut Out Just Before The Shout`のように
  **スタイル欄で「どこで楽器を抜くか」を書く**形は、この構造と原理が同じ。
  **ブラケット名ではなくスタイル欄の編成指示で作る**のが、実績のある近道になりそう
  (**これは推測。検証していない**)。
- **`[Post-Chorus]`は実績がある**(`songs/10-ame.md`、`reference/suno-samples.md`に2件)。
  **こちらが使っていないだけで、ユーザーは既に使っている。**

## 使い方

**新曲の構成を決める時、まず「どの形式か」を選ぶ。**
Verse-Chorus形式だけが選択肢ではない。Strophic・AABA・Through-composed・Verse-Refrainがある。

**Verse-Chorus形式を選んだ場合に限り**、その中で
Cメロ/大サビ/落ちサビ/Post-Chorusを入れるかを検討する。

**セクション名を並べ替えて変化を出そうとするのをやめる。**
それが「パラメータを1つ動かして条件を満たす」という、3回繰り返した失敗の形。

## ⚠️ この資料を「サビを減らす根拠」に使わない(2026-09-21にユーザーから明示)

> **verseとchorusは一回だけしか使えないなんて事はないんだからな？
> 1〜3、またはverseだけの構成だって良い**

**サビの無い形式(Strophic/AABA/Through-composed)を並べたのは、
選択肢を増やすためであって、サビを減らすことを推奨するためではない。**

- `Verse 1 / 2 / 3`も`Chorus 1 / 2 / Final Chorus`も**普通に使ってよい**
  (`songs/20-gacha-oni.md`は3サビ、`songs/11-000000-bug.md`はVerse 4まで)。
- **Verseだけの構成もよい**(=Strophic)。
- **回数は自由。1回でも3回でも、それ自体は良くも悪くもない。**

**`songs/25`でサビを1回にして「構成を変えた」と説明したのは誤り。**
回数は変化の条件ではない。**その形が内容から出てきたかどうかだけが基準。**
