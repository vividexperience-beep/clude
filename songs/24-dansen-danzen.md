# 断線 断然(タイトル仮)

ボーカル: YuRa(**SunoのVoice機能でYuRaを選択する前提**)
ジャンル: Glitch Pop Rock / Digital Alternative Rock(152Bpm)
テーマ: 壊れた機材を直さずそのまま鳴らす。破綻を音色として肯定する

**この曲は2026-09-16に明文化された【曲を考える時のルール】6項目に準拠した最初の曲。**

---

## 制作の軸(ユーザーとの4回の確認で確定)

1. **方向性**: ノイズ・破綻を音色にするダーク系(YuRaに前例なし)
2. **軸は物語ではなく韻とフロー**。破綻にまつわる言葉・近しい言葉・対比語の語感で作る
3. **フックは二字熟語を三連打する** → `断線 断然 完全`
4. **Verseはカタカナ脚韻で回す**
5. Voice機能を使うので、声の特性フレーズ(`Powerful Female Vocal`)は削除

---

## 韻の設計(検討用・Sunoには貼らない)

### フック — 二字熟語の三連打
```
断線(ダンセン) = a-n-e-n   破綻側
断然(ダンゼン) = a-n-e-n   強調(断固として)
完全(カンゼン) = a-n-e-n   対比側
```
**4モーラ×3＝12モーラ。三語とも実在の語で、三語とも母音が完全一致する。**
音がほぼ変わらないまま、意味だけが 切れた → 断固として → 完全 と動く。
同じ音を畳みかけて歌詞自体を打楽器のように機能させる技法(CLAUDE.md記載)の、
二字熟語による実装。**a-n-e-nは破綻側(断片・断線・暗転)と対比側(完全・安全・万全)が
3語ずつ揃う唯一のクラスタで、この曲の主張がそのまま韻の構造になっている。**

### Verse — カタカナ脚韻、Verseごとに母音を変える
| | 脚韻 | 母音 |
|---|---|---|
| Verse 1 | グリッチ / スイッチ / ピッチ | u-i-i |
| Verse 2 | ミュート / ルート / ブート | u-u-o |
| Verse 3 | クラッシュ / フラッシュ / ラッシュ | u-a-u |

厳密な母音一致より語感のリズムで踏む、`songs/05-told-you-so.md`で実証済みの
「カタカナ英語(外来語)での脚韻」路線。

### Breakdown — 二字熟語の羅列

破綻にまつわる二字熟語を母音・語尾のクラスタごとに洗い出し、**1行1クラスタ**で連打する。

| 母音／語尾 | 破綻側 | 対比側 |
|---|---|---|
| **a-n-e-n** | 断片・断線・暗転 | **完全・安全・万全** |
| **〜かい** | 崩壊・溶解・倒壊・決壊・分解・瓦解 | — |
| **〜おん** | 雑音・爆音・濁音・轟音・騒音 | 消音・防音 |
| **〜だん** | 寸断・分断・切断・中断・遮断 | — |
| **〜れつ/〜ねつ** | 亀裂・破裂・断裂・過熱 | — |
| i-n-o-u | 沈黙 | 均衡 |
| o-u-a | 飽和 | 調和 |

**a-n-e-nが最強のクラスタ。破綻側3語と対比側3語が同じ母音で真っ向から対になり、
しかもフックの着地点「完全」がその中にいる。**

実務上の発見として、**この手の二字熟語はほぼ全部4モーラ**(だ・ん・ぺ・ん / ざ・つ・お・ん /
ほ・う・か・い)。**4語並べるとちょうど16モーラ**になり、Verseの行(16モーラ)と
互換性がある。今回はBreakdownに置いたが、Verseに差し替えることも字数を壊さずにできる。

Breakdownの5行は 12 / 16 / 16 / 16 / 12 モーラで、
**亀裂→切断→轟音→崩壊** と破壊の規模が段階的に上がっていく。

### 洗い出した語彙(母音が完全一致したものだけ)
**漢語二字**
- a-n-e-n … 断片・断線 ↔ **完全**
- i-n-o-u … 沈黙 ↔ **均衡**
- o-u-a-i … 崩壊・溶解
- a-a-i / e-a-i … 瓦解 / 決壊

→ 破綻側2語と対比側1語が同韻になる **断片／断線／完全** が最も強く、ここからフックを作った。

**和語(採用分)**
- 破綻側: 抜けかけ・飛ぶ・裂ける・軋む・潰す・焦げる・割れる
- 対比側: 完全(フックのみ)

## 仕掛けの解説

- **Breakdownの最終行 `断片 断線 暗転——` が、韻そのもので期待を作って裏切る。**
  a-n-e-nを3語聴かせた時点で、聴き手の耳は4つ目に同じ母音の語を待つ。
  そこを切る。**待たされた「完全」が渡されるのはFinal Chorusが初めて。**
  Verse 3を丸ごと挟んでから回収するので、間が長いほど効く。
  「サビの同じ設問をFinal Chorusで初めて答えに変える」(問い→答えの構造)の変種を、
  意味ではなく**母音で**実装したもの。
- **Breakdownは打楽器が抜ける箇所なので、熟語の連打が打楽器の代わりになる。**
  `Percussion Drops Out In The Breakdown Then Returns Abruptly`(「自壊」で実証済み)と
  歌詞側の設計が噛み合っている。CLAUDE.mdの「同じ音・漢字を畳みかけて、歌詞自体を
  打楽器のように機能させる」技法を、二字熟語で実装した形。
- **`〜まま`が3回出てくる(抜けかけたまま / 歪んだままで / 焦げたままで)。**
  これは意図的。「直さずにそのまま鳴らす」がこの曲の主張そのもので、
  同じ語を畳みかけて芯にしている。不要ならVerse側を削れる。
- **場面は1つに統一している**(ステージと機材)。ジャック・ケーブル・メーター・針・
  スピーカー・客席・配線・基盤と、すべて同じ場所で自然に共存する物だけを選んだ
  (「具体的なディテールは1つの場面にまとめる」の実践)。

## 判断が分かれうる点(正直に記録)

- **サビのL1の語尾だけ揃っていない**(鳴らす / 飛ぶ / 止めない)。
  L3は3本とも動詞終止形のウ段(笑ってる / 唸る / 軋む)で揃えてあるが、
  Final ChorusのL1は「止まらぬ」にすれば揃う一方、**自動詞になって
  「自分で止めない」という意味が消える**ため、意味を優先して揃えなかった。
- **Breakdownの`飽和`は、`songs/11-000000-bug.md`(一ノ瀬柚葉)の冒頭
  「絶望……。 飽和……。」でも使われている語。** キャラクターも曲も別で、
  一般的な単語なので問題ないと判断したが、気になるなら`劣化`等に差し替え可能。
## 没にしたフック(記録)

初版のフックは **`断(だん)、done、それで完全`** という日英ダブル韻だった。
「日本語と英語の発音が近い語で韻を試せないか」というユーザーの要望から作ったが、
生成前にユーザーから「ここしっくりこない」と指摘され、原因を3つ特定して差し替えた。

1. **`断(だん)`が語として成立していない。** 単独の「断」を「ダン」とは読まない。
   聴き手の耳には**意味のない音が1語目に来る**ので、日英ダブル韻のつもりが
   実態は「意味のない音＋英語」で、**ダブルになっていなかった**。
2. **`それで`が情報量ゼロ。** 3モーラ使って何も言っておらず、フックの中央に穴が空いていた。
3. **`done`と`完全`が同じ側にいた。** done＝済んだ、完全＝complete で、どちらも
   「終わった・揃った」側。**破綻語を畳みかけて対比語にぶつける設計だったのに、
   実際は 断→完了→完全 と滑らかに繋がってしまい、衝突が起きていなかった。**
   これが最も大きい欠陥で、韻の形は合っているのに意味の運動が死んでいた。

**教訓: 日英ダブル韻を作るときは、(a)日本語側が単独で意味の通る語であること、
(b)二語が意味のベクトル上でも対立または前進していること、の2点を必ず確認する。**
音が一致しているだけでは韻は機能しない。

なお、この検討中に **`〜おん`で終わる二字熟語(雑音・爆音・濁音・轟音)は
すべて英語の`on`と同音**という発見があった。今回は採用しなかったが、
日英ダブル韻の素材として別の曲で使える。
